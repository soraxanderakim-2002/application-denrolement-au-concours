💾 DONNÉES STATIQUES (SANS BASE DE DONNÉES)

Le système fonctionne SANS base de données en mode SIMULATION.
Toutes les données sont simulées (hardcodées en PHP).

Pour utiliser une BDD MySQL réelle:
  1. Importer database.sql dans MySQL
  2. Configurer credentials dans admin/config.php
  3. Recommenter les fallbacks de données simulées
